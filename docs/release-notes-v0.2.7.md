# Portable LLM Council v0.2.7

The Factory adapter now follows the task lifecycle exposed in the current session. The shared Outsider assignment asks how an uncertainty affects the owner’s decision or what the owner should check. Get Started now names the ClearFold Laundry brief at the example link.

The Claude Code reference moved to `references/claude-code.md`. When upgrading by copying files into an existing installation, back up any local edits and remove the old package-owned `references/claude.md` from the shared skill. Leaving that filename in place can cause instruction discovery on case-insensitive volumes. If the Claude skill directory is a symlink, update its target and preserve the link.
