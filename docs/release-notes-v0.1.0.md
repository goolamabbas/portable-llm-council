# Portable LLM Council v0.1.0

A shared council skill with native subagent definitions for Codex, Cursor, Command Code, Grok Build, OpenCode, and Factory Droid. Adapted from Ole Lehmann's Claude-focused lens-based workflow, drawing on Andrej Karpathy's LLM Council.

Five advisors, five fresh blind reviewers, and one chair produce an HTML report and a Markdown transcript. No specific model is pinned. See the README for installation and harness execution guidance.

Claude Code and ordinary chat products are not included targets in this initial release.

Download GitHub’s automatic “Source code (zip)” asset below and follow its README, or clone the repository.
